# Threat Hunting with Wazuh and Atomic Red Team (SIEM Lab)

## Context

Semester project for the Cybersecurity 2 course at the Technological University of Panama.

The objective was to implement and evaluate a security infrastructure based on Wazuh (SIEM/XDR) to detect and analyze security events generated by simulated attacks, aligned with the MITRE ATT&CK matrix.

## Credits

Team project developed as part of the Cybersecurity II course.

**Personal Role**

- Installation and configuration of agents on Windows Server and Windows 10
- Execution of attacks from Kali Linux (Responder, CrackMapExec, Kerberoasting, BloodHound, Mimikatz)
- Documentation of technical findings and evidence
- Proposal of mitigations based on MITRE ATT&CK

## Techniques Used

### LLMNR/NBT-NS Reconnaissance and Poisoning (Responder)

Initial scanning with `nmap` and capture of NTLMv2 hashes using Responder over the tailnet interface.

### Password Spraying with CrackMapExec/Hydra

Credential validation against the DC using CrackMapExec, including domain group enumeration.

### Kerberoasting with Impacket and John the Ripper

Creation of a service account with an SPN, request of TGS tickets using `GetUserSPNs.py`, and offline cracking with John.

### Privilege Collection with BloodHound/SharpHound

Domain data collection with SharpHound and import into BloodHound to map privilege escalation paths.

### Lateral Movement (psexec, wmiexec, smbexec)

Use of compromised credentials for lateral movement and local privilege escalation.

Extraction of SAM hashes and LSA secrets from the domain controller.

### Atomic Test Execution with Atomic Red Team

Atomic tests mapped to 10 MITRE ATT&CK tactics (TA0043, TA0001, TA0002, TA0003, TA0004, TA0005, TA0006, TA0007, TA0008, TA0010), executed with the `Invoke-AtomicRedTeam` module in PowerShell.

## Detection

- Alerts generated in Wazuh correlated with Windows events (4625, 4769, 4104, etc.)
- Custom Sysmon and Wazuh rules for critical tactics (TA0043, TA0010)
- Monitoring of processes, LDAP/RPC connections, and memory dumps

screenshots/wazuh-mitre-detection.png

## Mitigation

- Disable LLMNR and NetBIOS through GPO.
- Enforce strong password policies and MFA.
- Restrict privileges on service accounts.
- Implement network segmentation and traffic filtering.
- Audit scheduled tasks and registry keys.
- Protect credentials using Credential Guard and EDR.
- Harden AD and GPO policies.

## Lessons Learned

- Practical understanding of the attack and defense cycle in corporate environments.
- Validation of a SIEM’s detection capabilities against MITRE ATT&CK techniques.
- Importance of rule tuning to reduce false positives.
- Relevance of combining detection, mitigation, and continuous monitoring to strengthen the security posture.
