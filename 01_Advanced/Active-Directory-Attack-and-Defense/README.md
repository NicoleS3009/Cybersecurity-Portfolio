# Threat Hunting with Wazuh and Atomic Red Team (SIEM Lab)

## Context
Semester project for the Cybersecurity II course at the Technological University of Panama.
The goal was to implement and evaluate a security infrastructure based on Wazuh (SIEM/XDR) to detect and analyze security events generated by simulated attacks, mapped to the MITRE ATT&CK matrix.

## Credits
Project developed as a team as part of the Cybersecurity II course.

**Personal role**
- Installation and configuration of agents on Windows Server and Windows 10
- Execution of attacks from Kali Linux (Responder, CrackMapExec, Kerberoasting, BloodHound, Mimikatz)
- Documentation of technical findings and evidence
- Proposal of mitigations based on MITRE ATT&CK

## Techniques Used

### LLMNR/NBT-NS Reconnaissance and Poisoning (Responder)
Initial scanning with `nmap` and capture of NTLMv2 hashes using Responder over the tailnet interface.

![Running Responder to capture NTLMv2 hashes](screenshots/responder-attack1.png)
![Captured NTLMv2 hashes](screenshots/responder-hash.png)

### Password Spraying with CrackMapExec/Hydra
Credential validation against the DC using CrackMapExec, including enumeration of domain groups.

![CrackMapExec authenticating against the DC](screenshots/crackmapexec.png)

### Kerberoasting with Impacket and John the Ripper
Creation of a service account with an SPN, requesting TGS tickets with `GetUserSPNs.py`, and offline cracking with John.

![Creating a service account with an SPN](screenshots/kerberoasting-setup.png)
![Requesting Kerberos tickets (TGS) for the SPN](screenshots/kerberoasting-hash.png)
![Cracking the Kerberos hash with John the Ripper](screenshots/kerberoasting-crack.png)

### Privilege Enumeration with BloodHound/SharpHound
Collecting domain data with SharpHound and importing it into BloodHound to map privilege escalation paths.

![Ingesting SharpHound data into BloodHound](screenshots/bloodhound-ingest.png)
![Privilege relationship graph in BloodHound](screenshots/bloodhound-graph.png)

### Lateral Movement (psexec, wmiexec, smbexec)
Using compromised credentials for lateral movement and local privilege escalation.

![Lateral movement adding a user to the Administrators group](screenshots/lateral-movement.png)

### Credential Dumping with Mimikatz and secretsdump
Extraction of SAM hashes and LSA secrets from the domain controller.

![Credential dumping with secretsdump](screenshots/secretsdump.png)

### Running Atomic Tests with Atomic Red Team
Atomic tests mapped to 10 MITRE ATT&CK tactics (TA0043, TA0001, TA0002, TA0003, TA0004, TA0005, TA0006, TA0007, TA0008, TA0010), executed with the `Invoke-AtomicRedTeam` PowerShell module.

## Detection

- Alerts generated in Wazuh correlated with Windows events (4625, 4769, 4104, etc.)
- Custom Sysmon and Wazuh rules for critical tactics (TA0043, TA0010).
- Monitoring of processes, LDAP/RPC connections, and memory dumps.

![Detection of MITRE techniques in the Wazuh dashboard](screenshots/wazuh-mitre-detection.png)

## Mitigation

- Disable LLMNR and NetBIOS via GPO.
- Strong password policies and MFA.
- Restrict privileges on service accounts.
- Network segmentation and traffic filtering.
- Audit scheduled tasks and registry keys.
- Credential protection (Credential Guard, EDR).
- Hardening of AD and GPO policies.

## Lessons Learned

- Practical understanding of the attack and defense cycle in corporate environments.
- Validation of a SIEM's detection capability against MITRE ATT&CK techniques.
- Importance of rule tuning to reduce false positives.
- Relevance of combining detection, mitigation, and continuous monitoring to strengthen security posture.
