// 01 — Perfil

Quién investiga este archivo

Ingeniería en Ciberseguridad en la Universidad Tecnológica de Panamá, con un punto de partida poco común: un background en Investigación Criminal.

Esa formación se traduce directamente en cómo trabajo la ciberseguridad: reconstruir la cadena de eventos, preservar evidencia, y entender el mecanismo de un ataque antes de diseñar la defensa que lo detiene.

Este repositorio agrupa laboratorios prácticos organizados por nivel de profundidad técnica — desde fundamentos criptográficos hasta pentesting de infraestructura Active Directory y arquitecturas Zero Trust.
